# Architecture decision records

An ADR records one decision we don't want to re-argue later: what we chose, what else we looked at, and why.

## Writing one

1. Copy `000-template.md` to `NNN-short-title.md`, using the next free number.
2. Fill it in with status **Proposed** and open a PR that links the decision's issue.
3. When the deciders approve, set the status to **Accepted** and merge.

Don't rewrite an accepted decision. If it changes, write a new ADR and mark the old one **Superseded by ADR-NNN**.
